# The Sorted Province

What actually divides British Columbia's voters — a scroll-driven data essay.

Riding-level analysis of BC provincial elections (2013-2024) against 2021 Census demographics:
education, home ownership, income, language, and age vs. NDP vote share and turnout.

Built from Elections BC official results and Statistics Canada census data.
All figures are computed from source data; methodology and caveats in the piece's endnote.

**Live:** https://mcallia.github.io/bc-sorted-province/
