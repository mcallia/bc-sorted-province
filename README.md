# BC Election Scrollies

Two scroll-driven data essays on British Columbia's electoral geography, built from
Elections BC official results and Statistics Canada census data.

**The Sorted Province** - what actually divides BC voters (education, ownership, age,
language - not income). BC elections 2013-2024 x 2021 Census.
https://mcallia.github.io/bc-sorted-province/

**The Path to the Majority** - the NDP's one-seat majority, mapped: regional blocs,
the suburban battleground, election-day neighbourhoods, and the advance-vote swing.
https://mcallia.github.io/bc-sorted-province/majority/

All figures computed from source data; methodology and caveats in each piece's endnote.
